# Movie Still Lobby Card Generator

A mobile-first, browser-based generator that creates a unique five-card lobby-card set from a user-supplied movie file.

## What it does

- Processes the movie locally; it is not uploaded.
- Samples scenes throughout the complete movie.
- Scores frames for clarity, contrast, color and visual detail.
- Rejects similar frames and remembers earlier selections for the same title on the device.
- Renders five 10×8-inch landscape cards at 300 DPI (3000×2400 PNG) with white borders.
- Charges one StarCoin only after all five cards have rendered successfully.
- Uses the shared Infinity unified wallet.

Only use public-domain, licensed, owned, or otherwise authorized footage.
